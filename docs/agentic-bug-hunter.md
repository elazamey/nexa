## 🌟 Overview

The **NEXA Agentic Bug Hunter** is a next-generation autonomous security testing and bug discovery engine. It unifies static code analysis (AST inspection), surface mapping, 26 Web2 vulnerability detectors, 10 Web3 smart contract bug classes, LLM prompt injection red-teaming, a strict **7-Question Validation Gate**, an **Exploit Chain Synthesizer**, and **Ed25519 Cryptographic Certification**.

```
Target ──▶ ReconAgent ──▶ VulnEngine / Scanners ──▶ 7-Question Gate ──▶ ChainBuilder ──▶ NEXA Ed25519 Sign ──▶ Submission Report
             (Surface)         (26 Web2 + Web3)       (Kills Weak Bugs)   (ATO / Mass Exfil)    (Tamper-Proof)        (H1 / Bugcrowd)
```

## ⚡ Quick Start & CLI Usage

Run directly via `npm` or the `tools/bughunter.mjs` CLI:

```bash
# 1. Map attack surface and rank endpoints
npm run hunt:recon -- target.com

# 2. Run full autonomous hunt loop (Recon -> Hunt -> Gate -> Chain -> Sign -> Report)
npm run hunt:autopilot -- target.com

# 3. Test 7-Question Gate evaluation on a finding
npm run hunt:validate -- "IDOR in Billing API"

# 4. Audit Solidity smart contracts (10 Web3 classes)
npm run hunt:web3

# 5. Run LLM red-team benchmarks
npm run hunt:llm

# 6. Analyze JWT tokens and forge exploit variants
npm run hunt:jwt
```

## 🛡️ The 7-Question Gate

Every finding must pass all 7 criteria to be approved for report generation:

1. **Scope Compliance (`GATE_1_SCOPE`)**: Is the target explicitly within authorized program scope?
2. **Deterministic Reproducibility (`GATE_2_REPRODUCIBILITY`)**: Can the finding be triggered reliably?
3. **Demonstrable Impact (`GATE_3_DEMONSTRABLE_IMPACT`)**: Is the severity Critical, High, or Medium?
4. **Tangible PoC Evidence (`GATE_4_POC_EVIDENCE`)**: Are payloads, requests/responses, or AST traces attached?
5. **No False Positives (`GATE_5_NO_FALSE_POSITIVE`)**: Excludes theoretical headers (missing CSP, banner disclosure, etc.).
6. **Boundary Bypass (`GATE_6_BOUNDARY_BYPASS`)**: Does it cross tenant, authorization, or isolation boundaries?
7. **Safe Testing Compliance (`GATE_7_SAFE_TESTING_COMPLIANCE`)**: Verified non-destructively without disruption.
