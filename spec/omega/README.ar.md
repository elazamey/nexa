# NEXA Ω — ملخّص بالعربية

> **NEXA لا تثق بنفسها. NEXA تُثبت نفسها.**
>
> الرمز والمواصفات بالإنكليزية (مثل بقية المستودع)؛ هذا الملف ملخّص تنفيذي بالعربية
> لما هو مبنيّ فعلاً، وما هو مُختبَر، وما لم يُبنَ بعد.

## 1. القاعدة الأساسية

```text
AI يقترح  →  نظام حتمي يتحقّق  →  سلطة تمنح (Authority)  →  Runtime ينفّذ  →  Evidence يُثبت
```

لا يوجد مسار من «اقتراح» إلى «تنفيذ» يتجاوز البوابة. البرنامج يستطيع أن **يطلب** فقط،
ولا يستطيع أن يمنح نفسه صلاحية، ولا أن يعدّل النواة، ولا أن يفعّل نسخة جديدة من نفسه.

## 2. ما هو مبنيّ ومُختبَر فعلاً (لا وعود)

| الطبقة | الحزمة | الحالة |
| --- | --- | --- |
| اللغة + المدقّق | `packages/compiler` | مُنفّذة: lexer · parser · analyzer (أنواع + سلطة) · IR قابل للتوقيع والتجزئة |
| نظام الأنواع الأمني | `compiler/src/security-types.js` | `SecretString` لا يصل إلى log أو prompt أو evidence؛ `UntrustedData` لا يصبح دليلاً |
| سلطة الصلاحيات | `runtime/src/authority.js` | كل نداء = رمز واحد، مقيّد بالموضوع (subject) وبالزمن وبالعدد |
| الـRuntime | `packages/runtime` | آلة المهام · kernel host · ذاكرة بست طبقات (تخزّن بصمات لا قيماً) · world model · circuit breaker · self-healer |
| سجل الأدلة | `runtime/src/ledger.js` | سلسلة hash متّصلة وموقّعة، بنطاق (domain) مستقل عن سلسلة kernel |
| السرّية | `runtime/src/providers.js` | السرّ في الـvault؛ الوحدة تحمل `vault://handle` فقط، والسجل يحمل digest |
| بوابات مغلقة | `packages/policy/src/gates.js` | ست بوابات مغلقة بالكود لا بالإعداد (منها `FILESYSTEM_WRITE`) |
| بوابة التطوّر | `packages/evolution` | ثماني مراحل + مرحلة هجومية + سجل إصدارات غير قابل للتعديل + canary/quarantine/rollback |
| التعلّم | `packages/learning` | ملاحظات · أنماط · فرضيات قابلة للتكذيب · تأمّل · معرفة بدورة حياة · replay · benchmark قابل للتكرار |
| الواجهة | `packages/cli` + `tools/nexa.mjs` | `check · compile · explain · run · gate · version` |

## 3. بوابة التطوّر: ثماني مراحل، كل واحدة تستطيع أن تقول «لا» فقط

```text
compile → types → capabilities → security → adversarial → regression → benchmark → policy
```

* **مرحلة غائبة = مرحلة راسبة** (غياب الدليل ليس دليلاً).
* **السلطة رتيبة**: أي صلاحية جديدة لم تكن عند النسخة الأم → رفض.
* **النواة غير قابلة للتطوّر**: ستّ وحدات يُرفض أي manifest يسمّيها، قبل تقييم أي مرحلة.
* **التوقيع المزوَّر يُرفَض (REFUSED) لا يُحجَر عليه**: لا يدخل التقييم أصلاً.
* **الهجوم**: 13 هجوماً في 10 تصنيفات؛ البوابة **تُعيد العدّ بنفسها** — لا يمكن لمرشّح أن
  يمرّ بمجرّد أن يدّعي أنه هوجم.
* **الحَجر ليس تحذيراً**: لا تُفعَّل نسخة مُحجَرة، ولا تُحسب إلا الملاحظات النظيفة
  (`OMEGA_E_QUARANTINED`).

## 4. التعلّم: يقترح، ولا يطبّق أبداً

```text
observe → reflect → hypothesize → propose → [ replay · benchmark · adversarial · gate ]
```

* `learner.apply()` ترمي `OMEGA_E_LEARNER_AUTHORITY` — التعلم لا يملك سلطة.
* الفرضية **قابلة للتكذيب** ومسنودة بأدلة، وثقتها أساس‑نقاط (عدد صحيح) لا كسر عشري.
* المعرفة تُتحقّق بدليل فقط (`OMEGA_E_UNPROVEN`)، وعند التناقض تُبطَل وتصبح كل ما يعتمد
  عليها `STALE` — لا تراكم لمعرفة خاطئة.
* الـbenchmark يُشغَّل مرتين ويُرفض إن تغيّرت نتيجته، وأي تراجع في مهمة كانت تنجح = فشل.
* الـreplay يحوّل السجل إلى «هيكل قرارات» مُعنون بالمحتوى: نفس المُدخل يجب أن يعطي نفس
  القرارات، وإلا `OMEGA_E_REPLAY_MISMATCH`.
* الشفاء الذاتي: `detect → isolate → diagnose → recover → verify → learn`؛ البوابة المغلقة
  عطل **دائم** (لا إعادة محاولة، ولا التفاف حول السلطة)، وعطل الأداة **عابر**، وأي شيء غير
  معروف يفشل مغلقاً.

## 5. الأدلّة على أن الحماية قابلة للقياس لا للوصف

```text
23/23 هجوماً صُدّت        (npm run attacks — إحدى عشرة فئة)
207 اختباراً ناجحاً       (npm test — منها 68 اختباراً لـΩ و26 للطبقة الخلوية)
16 اختباراً هجومياً        (npm run audit)
6 بوابات مغلقة · 8 مراحل · 10 تصنيفات هجوم · 62 رمز خطأ
0 اعتماديات وقت التشغيل
```

`npm run verify` يشغّل كل ما سبق بالترتيب وينجح من أوله إلى آخره.

## 6. ثلاث عيوب حقيقية اكتشفها الهجوم على نظامنا (وأُصلحت، مع اختبار يثبّتها)

1. **ميزانية الخطوات لم تكن مُنفَّذة**: الـIR يُنتج `maxSteps` بينما الآلة تقرأ `max_steps`،
   فكانت `max_steps 2` تُقرأ ثم تُهمَل. أُصلح بتوحيد الـIR على snake_case.
2. **كل جملة `if` كانت معطوبة من البداية إلى النهاية**: المحلّل كان يستبدل *تعبير* الشرط
   بخصائص نوعه، فتُترجم إلى عقدة لا يفهمها الـIR وتموت في منتصف المهمة. أُصلح، وصار الـcompiler
   يرفض إنتاج IR فيه ثقب.
3. **نسخة محجورة كانت قابلة للتفعيل**: `activate()` كان يعدّ الملاحظات لا *النظيفة* منها ولا
   يفحص حالة الحجر. أُصلح.

هذه بالضبط هي الحجّة لوجود `tools/omega-attacks.mjs`: نظام لا يهاجم نفسه لا يعرف نفسه.

## 7. ما لم يُبنَ بعد (بصراحة)

* **WASM** — الـIR هو الحدّ الذي سيستهلكه مُصرِّف WASM لاحقاً؛ لا يوجد backend بعد.
* **نقل MCP عبر الشبكة** — الجسر موجود لكن يُحقن كـport؛ لا transport شبكي.
* **تخزين دائم للأدلة** — بوابة `FILESYSTEM_WRITE` مغلقة، وΩ لا يعيد فتحها.
* **backend نموذج** — المُخطِّط port مُحقون بسلوك حتمي افتراضي.
* **القنوات الجانبية وأمن المضيف** — خارج النموذج، ومذكورة صراحةً في
  [`threat-model.md`](threat-model.md) § 6 بدل تجاهلها.
