# 🌐 نظام تشغيل وحوكمة وكلاء الذكاء الاصطناعي المجاني لعام 2026 (NEXA AI Agent OS)

> **نظام تشغيل وحوكمة متكامل ومستقل، مجاني أولاً (Free-First)، متعدد البروتوكولات، ومدعوم بالتوقيع الرقمي الحتمي Ed25519.**
> يدمج تشغيل النماذج المحلية (Ollama / llama.cpp)، وبروتوكولات MCP و A2A، والذاكرة الزمنية (Temporal Knowledge Graph)، والتحكم الآمن في الحاسوب (Computer Use).

## 🧩 الطبقات المعمارية الثمانية الأساسية

### 1. شبكة النماذج المحلية المجانية (Zero-Cost Local Model Mesh)
- **أولوية التشغيل المجاني**: الاعتماد المباشر على المحركات المحلية مثل **Ollama** و **llama.cpp** بدون الحاجة لأي اشتراك أو API Key خارجي.
- **توجيه المهام الذكي**: توجيه الطلبات تلقائياً للنموذج الأنسب والأخف وزناً بحسب طبيعة المهمة (برمجة، تفكير منطقي، رؤية حاسوبية، محادثة عامة).

### 2. تكامل البروتوكولات المتعددة (Multi-Protocol Bridge)
- دعم **MCP (Model Context Protocol)** و **A2A (Agent-to-Agent)** و **OpenAPI**.
- **المبدأ الأساسي**: *الاتصال للأدوات، والسلطة لنظام NEXA* — الأدوات تتيح الوظائف، لكن تنفيذها مشروط ببوابة السياسات الرقمية.

### 3. الذاكرة رباعية المستويات والرسم البياني المعرفي الزمني (Temporal Knowledge Graph)
- **الذاكرة العاملة (Working Memory)**: مسودة سريعة للمهام الجارية.
- **الذاكرة الحلقية (Episodic Memory)**: تسجيل جلسات التنفيذ السابقة مع بصمة SHA-256 الرقمية.
- **الذاكرة الدلالية (Semantic Memory)**: تخزين المفاهيم والحقائق المكتسبة.
- **الذاكرة الإجرائية (Procedural Memory)**: خطوات العمل والمهارات المجربة والموثقة.

### 4. واجهة الكمبيوتر والتحكم الآمن (Computer Use & Sandboxing)
- **الطرفية (Terminal)**: قائمة برامج بيضاء مسموحة مع حظر تجاوز المسارات وعزل كامل.
- **المتصفح (Browser)**: تنفيذ خطوات التصفح والاستخراج المتوافقة مع Playwright و `browser-use`.

### 5. حوكمة Zero-Trust والسجل الحتمي الموقّع بـ Ed25519
- **سياسة الرفض الافتراضي (Default-Deny)**: لا يُسمح بأي إجراء دون توكن صلاحية ساري.
- **سلسلة أدلة غير قابلة للتلاعب**: كل قرار وإجراء يتم توقيعه رقمياً وتضمينه في سجل تاريخي متسلسل.

### 6. التحسين الذاتي الآمن والمحكوم (Self-Improvement Pipeline)
- مسار ترقية آمن من 6 مراحل يضمن عدم تعديل أي كود دون اختبارات عزل وفحص أمني شامل.
